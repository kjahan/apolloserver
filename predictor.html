Step I

You need to upload your CSV file to the server for the time series analysis.

The input to Predictor should be a CSV file with two columns: 'ds' and 'y'. The 'ds' (datestamp) column in the format of "YYYY-MM-DD" for a date or "YYYY-MM-DD HH:MM:SS" for a timestamp. The 'y' column must be numeric, and represents the measurement you wish to forecast.

Step II

Then you can train a model with your historical data. Fitting should take 1-5 seconds.

Predictions are then made for the requested number of days in the future (e.g. 365). By default the predictions will also include the dates from the history, so you will see the model fit as well.

Step III

The `predict` method will assign each row in `future` a predicted value which it names `yhat`. If you pass in historical dates, it will provide an in-sample fit. The `forecast` object here is a new dataframe that includes a column `yhat` with the forecast, as well as columns for components and uncertainty intervals.
