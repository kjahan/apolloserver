# apollo-server

Apollo server applications are a suite of web apps that work with our HTTP server which provides a number of different forecasting services.

## Predictor app

Open the following URL in your browser to upload your data and start the forecasting analysis:

`http://localhost/apolloserver/predictor.html`

## Market app

Open the following URL in your browser and enter the market symbol and number of days to run the price forecasting for:

`http://localhost/apolloserver/market.html`

## Stock recommender app

Open the following URL in your browser to get recommendations for stocks with outperforming performance:

`http://localhost/apolloserver/recommender.html`
